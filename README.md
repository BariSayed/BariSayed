Bioinformatician and **Assistant Professor** in the *Department of Aquatic Animal Health Management*,
**Sher-e-Bangla Agricultural University (SAU)**, Dhaka, Bangladesh. I build reproducible, Linux-based
**omics pipelines** and apply **genomics, transcriptomics and metagenomics** to decode health, immunity
